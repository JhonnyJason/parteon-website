# Task
Turning the [prospectus](prospectus.pdf) into the static website built like the regular thingy-ui.

## Details
The Prospectus contains Background images, fonts and text content, that is the base content to be used for the website.
It must be optimized to not be too large and not load all at once - as well as good SEO practices should be applied.
For that purpose the content might divert from the prospectus.
Important is some interactivity that it feels less like a "generic" website.
For that purpose the customer wants a flow which "simulates" the slides while scrolling:

### Simulating the Slides
Wevery Slide should be fullpage display, when the user scrolls down then it swaps to the next Slide, and for every slide we have a background and a content Overlay. The content overlay should be organized in such a way that the content always fits on the Screen. On Portrait Mode - which is most probably a mobile device -  we most probably loose visibility of the background images though - and might decide to not even load them to save data.
